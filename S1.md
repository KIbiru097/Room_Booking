Design a premium, production-ready **YayeTech / LuxStay Staff Operations Portal** for hotel front-desk and daily hotel operations.

Create a modern **desktop-first responsive dashboard** with a clean luxury hospitality aesthetic: Swiss minimalism + subtle glassmorphism, generous spacing, rounded cards, elegant typography, soft shadows, professional hotel imagery, and excellent light/dark mode support.

### Main Layout

* Left sidebar navigation with YayeTech logo and STAFF identity.
* Top bar with:

  * Assigned hotel selector
  * Global search
  * Notifications
  * Language switcher: English / Amharic
  * Staff avatar and profile menu
* Clearly display the currently selected hotel.
* Never make the UI look like an admin panel; this is an **operations workspace**.

Show:

### Hotel Selector

Because one STAFF account can belong to multiple hotels, design a prominent hotel switcher:

"Current Hotel: YayeTech Grand Hotel"

Dropdown:

* Hotel A
* Hotel B
* Hotel C

Changing the hotel refreshes all operational data.

Clearly show the selected hotel throughout the interface.

### Permission-Aware UI

The interface must dynamically hide actions when the staff member lacks the corresponding permission.

Examples:

* No `booking.checkin` → hide Check-in
* No `booking.checkout` → hide Check-out
* No `payment.mark_cash_paid` → hide Cash Received
* No `booking.no_show` → hide No-show
* No `booking.relocate` → hide Relocate Room

Never imply that frontend visibility provides security. The backend remains the authorization source.
